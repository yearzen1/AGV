# 如何编辑车间地图

适用场景：在「车间地图」里预览、检查或修改路网，包括缩放、多选、对齐、拆分路段、导出图片和 3D 预览。

## 前置条件

- 已启动后端和前端，浏览器打开 <http://localhost:5173>。
- 已登录。`admin` 可以修改任何路网；`dispatcher` 修改预置模板后只能另存为副本。

## 1. 预览模式与编辑模式

打开路网后默认进入**预览模式**：可以缩放、平移、选择、查看详情和导出，但不能修改节点和路段。

- 点右上角「编辑」进入编辑模式，工具栏出现新建、删除、对齐等操作。
- 点「预览」回到只读状态，未保存的修改会先提示保存。
- 预置模板在预览模式下是只读的；`admin` 点「编辑」后可直接改，但建议先「另存为」。

## 2. 查看地图

| 操作 | 方式 |
|---|---|
| 放大/缩小 | 鼠标滚轮，以指针位置为中心，范围 40%–400% |
| 按钮缩放 | 工具栏 `−` / `+` |
| 重置为 100% | 点击工具栏中间的百分比 |
| 适应窗口 | 「适应窗口」，按全部节点计算 |
| 适应选中 | 选中元素后点「适应选中」 |
| 适应错误 | 有校验错误时点「适应错误」 |
| 平移 | 按住 `空格` + 左键拖动，或按住鼠标中键拖动 |
| 全屏 | 画布右上角「全屏」，再按一次或 `Esc` 退出 |
| 小地图 | 右下角缩略图；点击或拖动小地图可快速移动视图 |

画布左下角显示比例尺，状态栏显示当前光标坐标（米）。

## 3. 显示选项

工具栏「显示」里可以开关：

- 节点标签（`W1`、`CH1`…）
- 路段标签（`E1 · 3.2m`）
- 背景网格
- 任务流向

图例固定显示在画布左下角，说明节点类型颜色、单向/双向路段和错误高亮。

## 4. 选择与检查

### 选择

| 操作 | 结果 |
|---|---|
| 单击节点或路段 | 替换当前选择 |
| `Ctrl` / `Cmd` + 单击 | 增减选择 |
| 在空白处拖矩形 | 框选节点，以及两端都在框内的路段 |
| `Ctrl` / `Cmd` + 框选 | 追加选择 |
| 「全选」或 `Ctrl/Cmd+A` | 选中全部节点和路段 |
| 「清空」或 `Esc` | 清空选择 |

### 悬停详情

鼠标停在节点上显示编号、类型、坐标；停在路段上显示编号、起终点、长度、方向、速度、容量。

### 校验错误定位

右侧校验列表中的每条错误都可以点击，视图会自动缩放到对应节点或路段。错误元素红色高亮；工具栏显示错误数量。

## 5. 编辑节点和路段

### 新建节点

1. 进入编辑模式。
2. 选择「工位」「充电位」「缓存位」或「路口」。
3. 单击空白处，节点按 0.5 米吸附并自动编号。

画布范围由「画布尺寸」决定（默认 50×34 米，可改 10–200 米），点击范围外不会新增节点。

### 新建路段

选「连路段」，依次点击两个节点。默认双向、速度 1、容量 1；长度由两端坐标自动计算，不可手改。

### 拖动与多选拖动

- 拖动一个节点时，所有选中节点一起移动；选中路段的端点也会一起移动。
- 位移按 0.5 米吸附，整组不会拖出画布。
- 按住 `Shift` 拖动：锁定水平或垂直方向。
- 选中单个节点时，靠近其他节点的 X/Y 会出现对齐辅助线并自动吸附。

### 对齐与分布

多选节点后可用：

- 左对齐、水平居中、右对齐
- 顶对齐、垂直居中、底对齐
- 水平等距、垂直等距（至少 3 个节点）

### 批量属性

- 多选节点：批量设置节点类型。
- 多选路段：批量设置方向、速度、容量。

### 拆分、合并、反转

- **拆分路段**：双击路段，在点击位置插入一个路口节点，原路段拆成两段。
- **合并路段**：选中两条共享端点的路段，点「合并路段」；中间节点被移除。
- **反转方向**：选中单向路段后点「反转方向」，交换起点和终点。

### 复制、粘贴、再制

- `Ctrl/Cmd+C` 复制选中节点及内部路段。
- `Ctrl/Cmd+V` 粘贴，自动偏移 1 米并重新编号。
- `Ctrl/Cmd+D` 直接再制一份。

### 撤销与重做

- `Ctrl/Cmd+Z` 撤销。
- `Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做。
- 工具栏也有对应按钮，历史上限 60 步。

### 搜索与右键菜单

- 工具栏搜索框按编号查找节点/路段，`Enter` 循环定位。
- 右键画布可新建节点；右键节点/路段可删除、拆分、反转、适配视图。

### 属性面板

- 单个节点：编号、类型、X、Y。X/Y 超出画布会被钳制。
- 单条路段：编号、方向、速度、容量；长度只读。
- 多选：显示批量编辑入口和已选数量。

### 编号重复

节点或路段编号改成已存在的值时，会立即提示并还原，不需要等到校验。

## 6. 数据安全

- 切换路网、新建、离开页面前，如果有未保存修改，会弹出确认。
- 删除包含节点的选择时会二次确认。
- 修改节点坐标后，关联路段长度立即重算。
- 编辑内容每秒自动保存到浏览器草稿；重新打开同一路网时可恢复。
- 停止操作 600ms 后自动校验，工具栏显示错误数量；也可以在「显示」里关闭自动校验。
- `Ctrl/Cmd+S` 保存。

## 7. 画布尺寸

工具栏「画布」可修改宽度和高度（10–200 米）。

- 缩小画布时，超出范围的节点会被移动到边界上。
- 尺寸会随路网 JSON 保存和导出，旧路网默认 50×34。

## 8. 3D 预览与任务叠加

- 「3D 预览」用 Three.js 查看当前路网，支持旋转、缩放、平移。
- 选择任务集并打开「任务流向」，画布上会标出每条任务的起终点和流向，工位旁显示任务数量。

## 9. 导出

- 「导出 PNG」：导出当前视图，适合放进答辩 PPT。
- 「导出 SVG」：导出矢量图，可继续编辑。
- 「导出 JSON」：只导出路网数据，不包含缩放、选择和显示状态。

## 10. 校验、保存、导入

- 「校验」：调用后端 7 条规则，问题标红并显示在右侧。
- 「保存」：保存到当前路网；新建时需要先填名称。
- 「另存为」：复制为新路网。
- 「导入 JSON」：导入后自动校验；缺少尺寸字段时按 50×34 处理。

## 11. 快捷键

| 快捷键 | 作用 |
|---|---|
| 滚轮 | 以指针为中心缩放 |
| `空格` + 左键 | 平移画布 |
| 中键拖动 | 平移画布 |
| `Ctrl/Cmd+A` | 全选 |
| `Ctrl/Cmd+C` / `V` / `D` | 复制 / 粘贴 / 再制 |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl/Cmd+S` | 保存 |
| `Delete` / `Backspace` | 删除选中 |
| `Esc` | 清空选择或关闭弹层 |
| 方向键 | 选中节点移动 0.5 米 |
| `Shift` + 方向键 | 选中节点移动 2.5 米 |
| `Shift` + 拖动 | 锁定水平/垂直 |
| `?` | 打开快捷键帮助 |

快捷键只在鼠标位于画布内、焦点不在输入框时生效。

## 12. 验证清单

- 单向路段有箭头，图例能对应颜色和线型。
- 缩放时比例尺和光标坐标同步变化。
- 悬停节点/路段能看到详情。
- 小地图能反映当前视口，点击可跳转。
- 校验错误点击后能居中显示。
- 编辑模式下可撤销/重做、复制粘贴、对齐。
- 双击路段能拆成两段；两条相邻路段能合并；单向路段能反转。
- 修改 X/Y 后关联路段长度变化。
- 切换路网时未保存修改会提示。
- 导出 PNG/SVG 内容与当前视图一致。
- 3D 预览能旋转缩放；任务流向能显示起终点。
- 修改画布尺寸后保存、刷新仍然生效。
