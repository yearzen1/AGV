# 如何编辑车间地图

适用场景：在「车间地图」里预览、检查或修改路网，包括缩放、多选、对齐、拆分路段、导出图片和 3D 预览。

## 前置条件

- 已启动后端和前端，浏览器打开 <http://localhost:5173>。
- 已登录。`admin` 可以修改任何路网；`dispatcher` 修改预置模板后只能另存为副本。

## 1. 预览模式与编辑模式

打开路网后默认进入**预览模式**：可以缩放、平移、选择、查看详情和导出，但不能修改节点和路段。工具栏会显示「预览模式 · 点「编辑」可修改」，视图默认显示整个可画布范围（100%）。

- 想聚焦到已有节点时点「适应窗口」；点工具栏百分比或「100%」恢复整张画布。
- 点右上角「编辑」进入编辑模式，工具栏出现新建、删除、对齐等操作。
- 工具栏按「模式 / 节点 / 编辑 / 视图」分组；窄窗口下收起平移按钮、压缩搜索框，低频操作放在「更多」。
- 预览模式下拖动节点或路段只会选中，不会移动，并提示先点「编辑」。
- 点「预览」回到只读状态；未保存的修改会保留，重新点「编辑」可继续。

## 2. 查看地图

| 操作 | 方式 |
|---|---|
| 放大/缩小 | 鼠标滚轮，以指针位置为中心，范围 40%–400% |
| 按钮缩放 | 工具栏 `−` / `+` |
| 重置为 100% | 点击工具栏中间的百分比 |
| 适应窗口 | 「适应窗口」，按全部节点计算 |
| 适应选中 | 选中元素后点「更多」里的「适应选中」 |
| 适应错误 | 有校验错误时点「更多」里的「适应错误」 |
| 平移 | 选工具栏「平移」后左键拖动 |
| 定向平移 | 缩放组右侧 `←` `→` `↑` `↓`，每次 80px，长按连续移动；窄窗口用方向键平移 |
| 键盘平移 | 没有选中节点时，方向键移动视图；`Shift` 加速 |
| 平移（快捷键） | 按住 `空格` + 左键拖动，或按住鼠标中键拖动 |
| 全屏 | 画布右上角「全屏」，再按一次或 `Esc` 退出；浏览器不支持原生全屏时自动切页面内全屏 |
| 小地图 | 默认在窄窗口收起；点右上角「概览」展开，点小地图右上角 `−` 收起；点击或拖动小地图可快速移动视图 |

画布尺寸在工具栏「显示」里修改，画布边框和顶部/左侧每 10 米刻度表示可放置节点的范围。

画布左下角显示比例尺，状态栏显示当前光标坐标（米）。平移工具、空格/中键平移和拖动节点使用深色手形光标，浅色网格上也能看清；预览模式节点/路段使用深色指针。

### 光标速查

| 光标 | 出现场景 |
|---|---|
| 深色箭头 | 画布空白、选择/预览模式 |
| 深色指针 | 预览模式悬停节点/路段 |
| 深色手形 | 平移工具、空格/中键平移、编辑模式节点/路段 |
| 深色握拳 | 正在拖动节点、平移画布或小地图 |
| 深色十字 | 工位/充电位/缓存位/路口/连路段工具 |
| 小地图手形 | 悬停小地图；拖动时变为握拳 |

## 3. 显示选项

工具栏「显示」里可以开关：

- 节点标签（`W1`、`CH1`…）
- 路段标签（`E1 · 3.2m`）
- 背景网格
- 任务流向
- 画布宽度和高度（10–200 米，编辑模式下可改）

图例默认在宽窗口显示、窄窗口收起为左下角「图例」按钮；点击展开或收起，选择会记住。图例说明节点类型颜色、单车道单向/双向、双车道双向和错误高亮。

## 4. 选择与检查

### 选择

| 操作 | 结果 |
|---|---|
| 单击节点或路段 | 替换当前选择 |
| `Ctrl` / `Cmd` + 单击 | 增减选择 |
| 在空白处拖矩形 | 框选节点，以及两端都在框内的路段 |
| `Ctrl` / `Cmd` + 框选 | 追加选择 |
| 「全选」或 `Ctrl/Cmd+A` | 选中全部节点和路段 |
| 「清空」或 `Esc` | 清空选择 |

### 悬停详情

鼠标停在节点上显示编号、类型、坐标；停在路段上显示编号、起终点、长度、方向、速度、容量。

### 校验错误定位

右侧面板分成「属性」「统计」「校验」三个页签，选中元素后自动切到「属性」；「校验」页签显示当前问题数。

校验页签中的每条错误都可以点击，视图会自动缩放到对应节点或路段。错误元素红色高亮；工具栏显示错误数量。

校验列表最多占用约 240px 高度，超出后在列表内部滚动；各页签内容过多时只在侧栏内部滚动。画图过程中错误数量增减、选中元素切换都不会改变页面高度和画布尺寸，地图不会出现位移或跳动。

## 5. 编辑节点和路段

### 新建节点

1. 进入编辑模式。
2. 选择「工位」「充电位」「缓存位」或「路口」。
3. 单击空白处，节点按 0.5 米吸附并自动编号。

画布边框和顶部/左侧每 10 米刻度就是可放置范围，由「显示 → 画布尺寸」决定（默认 50×34 米，可改 10–200 米）。点击边框外不会新增节点，会提示先调整画布尺寸。

缓存位应放在主通道旁的支路末端，只连接一条路段；如果把缓存位串在两条路段中间，校验会报 `BUFFER_NOT_LEAF`。

所有节点默认容量为 1，可在属性面板单独修改：

| 节点 | 默认容量 | 说明 |
|---|---|---|
| 路口 | 1 | 临界区，一次一车 |
| 工位 | 1 | 一次一台车装卸 |
| 缓存位 | 1 | 单货位；多货位可把容量设为 2 或更多 |
| 充电位 | 1 | 单充电位；标准模板的 CH1/CH2 显式配置为 4，用于多车排队 |

容量小于 1 会被校验拦截。

### 新建路段

选「连路段」，依次点击两个节点。默认双向、单车道、速度 1、容量 1；长度由两端坐标自动计算，不可手改。

- 选中第一个节点后，画布顶部会提示「已选起点 W1」，按 `Esc` 可取消。
- 两个节点之间已有路段时不会重复创建，并提示「W1 与 J1 之间已有路段」。
- 两次点到同一个节点时提示「起点和终点不能相同」并取消本次连接。

新建路段的起点是第一个点击的节点，终点是第二个。选中路段后可把「方向」改成「单向」，箭头从**起点指向终点**；要改朝向，用属性面板的「交换」或工具栏「反转」，两者等价。

路段的「车道」有两种：

| 车道 | 方向 | 通行规则 |
|---|---|---|
| 单车道 | 单向 | 只允许一个方向，整条路段同一时刻一辆车 |
| 单车道 | 双向 | 两个方向共用一条路，同一时刻只允许一辆；对向车在端点等待 |
| 双车道 | 双向 | 两条平行车道，两个方向可同时各有一辆；同方向按「容量」排队 |

单车道双向用于窄巷道；双车道双向用于宽巷道。方向改成单向时，车道强制回到单车道。

### 拖动与多选拖动

- 拖动一个节点时，所有选中节点一起移动；选中路段的端点也会一起移动。
- 位移按 0.5 米吸附，整组不会拖出画布。
- 按住 `Shift` 拖动：锁定水平或垂直方向。
- 选中单个节点时，靠近其他节点的 X/Y 会出现对齐辅助线并自动吸附。

### 对齐与分布

多选节点后可用：

- 左对齐、水平居中、右对齐
- 顶对齐、垂直居中、底对齐
- 水平等距、垂直等距（至少 3 个节点）

### 批量属性

- 多选节点：批量设置节点类型。
- 多选路段：批量设置方向、速度、容量。

### 拆分、合并、反转

- **拆分路段**：双击路段，在点击位置插入一个路口节点，原路段拆成两段。
- **合并路段**：选中两条共享端点的路段，点「合并」；中间节点被移除。
- **反转方向**：选中单向路段后点「反转」或右键「反转方向」，交换起点和终点；也可以在属性面板点「交换」。双向路段没有固定朝向，该操作不可用。
- 2D 画布和 3D 预览都把方向箭头画在路段中部，而不是贴在节点上，所以短路段和 40% 缩放下也能看清朝向。

### 复制、粘贴、再制

- `Ctrl/Cmd+C` 复制选中节点及内部路段。
- `Ctrl/Cmd+V` 粘贴，自动偏移 1 米并重新编号。
- `Ctrl/Cmd+D` 直接再制一份。

### 撤销与重做

- `Ctrl/Cmd+Z` 撤销。
- `Ctrl/Cmd+Shift+Z` 或 `Ctrl+Y` 重做。
- 工具栏也有对应按钮，历史上限 60 步。

### 搜索与右键菜单

- 工具栏搜索框按编号或节点类型查找节点/路段。
- 搜索框为空时，右侧按钮显示「查找」并禁用；输入后按钮显示命中数量。
- 按 `Enter` 或点命中数量按钮循环定位，每次选中并缩放到对应元素；修改搜索词后从第一个命中重新开始。
- 没有命中时点按钮提示「没有匹配的节点或路段」。
- 右键画布可新建节点；右键节点/路段可删除、拆分、反转、适配视图。

### 属性面板

- 单个节点：编号、类型、容量、X、Y。X/Y 超出画布会被钳制。
- 单条路段：编号、方向、朝向（起点 → 终点）、车道、速度、容量；长度只读。单向路段可点「交换」改朝向，双向路段显示「双向无固定朝向」，按钮置灰。
- 箭头颜色跟随路段状态：默认灰、选中深蓝、校验错误红色；单向只画一个箭头，双向单车道在路段中部画两个反向箭头，双车道每条车道各一个。
- 多选：显示批量编辑入口和已选数量；节点可批量设置类型和容量。
- 路段的「容量」在双车道下表示每个方向的容量；节点容量表示可同时停靠的 AGV 数。

### 编号重复

节点或路段编号改成已存在的值时，会立即提示并还原，不需要等到校验。

## 6. 数据安全

- 切换路网、新建、离开页面前，如果有未保存修改，会弹出确认。
- 删除包含节点的选择时会二次确认。
- 修改节点坐标后，关联路段长度立即重算。
- 编辑内容每秒自动保存到浏览器草稿；重新打开同一路网时可恢复。
- 停止操作 600ms 后自动校验，工具栏显示错误数量；也可以在「显示」里关闭自动校验。
- `Ctrl/Cmd+S` 保存。

## 7. 画布尺寸

工具栏「显示」里的「画布尺寸」可修改宽度和高度（10–200 米）。

- 尺寸会随路网 JSON 保存和导出，旧路网默认 50×34。
- 修改后视图自动回到 100%，边框、刻度和可编辑范围同步更新。
- 缩小画布时，超出范围的节点会被移动到边界上。
- 预览模式下尺寸输入仍显示，但需要点「编辑」后修改。

## 8. 3D 预览与任务叠加

- 「3D 预览」用 Three.js 查看当前路网，左键旋转、滚轮缩放、右键平移。
- 弹窗底部提供「重置视角」「全屏」操作和操作提示；全屏后按钮变为「退出全屏」。
- 单车道画一条线和方向锥；双车道画两条平行线，每条车道各有一个方向锥。
- 「任务流向」只列出与当前路网绑定的任务集；切换路网时，不属于新路网的任务集会被清空。选中任务集后打开「在地图上显示任务流向」，画布上会标出每条任务的起终点和流向，工位旁显示任务数量。任务集与路网的绑定规则见 [维护任务集.md](维护任务集.md)。
- 同一组起点和终点的多条任务会合并成一条流向线，并在线上显示任务数量，避免多条线重叠。

## 9. 导出

- 「导出 PNG」：导出整张地图，适合放进答辩 PPT。
- 「导出 SVG」：导出整张地图的矢量图，可继续编辑。
- 「导出 JSON」：只导出路网数据，不包含缩放、选择和显示状态。

## 10. 校验、保存、导入

- 「校验」：调用后端 8 条规则，问题标红并显示在右侧「校验」页签。
- 「保存」：保存到当前路网；新建时需要先填名称。
- 「另存为」：复制为新路网。
- 「导入 JSON」：导入后自动校验；缺少尺寸字段时按 50×34 处理。

## 11. 快捷键

| 快捷键 | 作用 |
|---|---|
| 滚轮 | 以指针为中心缩放 |
| `空格` + 左键 | 平移画布 |
| 中键拖动 | 平移画布 |
| `Ctrl/Cmd+A` | 全选 |
| `Ctrl/Cmd+C` / `V` / `D` | 复制 / 粘贴 / 再制 |
| `Ctrl/Cmd+Z` / `Ctrl/Cmd+Shift+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl/Cmd+S` | 保存 |
| `Delete` / `Backspace` | 删除选中 |
| `Esc` | 清空选择、退出页面内全屏或关闭弹层 |
| 方向键 | 有选中节点时移动 0.5 米；无选中时平移视图 |
| `Shift` + 方向键 | 选中节点移动 2.5 米；无选中时加速平移 |
| `Shift` + 拖动 | 锁定水平/垂直 |
| `?` | 打开快捷键帮助 |

快捷键只在鼠标位于画布内、焦点不在输入框时生效。

## 12. 验证清单

- 打开路网后默认显示整个可画布范围（100%），页面不出现纵向滚动。
- 1440×900 下工具栏不超过两行，画布高度不小于 420px。
- 小地图和图例可折叠，展开时不遮挡当前节点。
- 单向路段箭头画在路段中部，短路段和 40% 缩放下也可见；属性面板交换起终点后箭头随之反转。
- 单车道双向对向车串行，双车道双向对向车可同时通过。
- 缩放时比例尺和光标坐标同步变化。
- 悬停节点/路段能看到详情。
- 小地图能反映当前视口，点击可跳转。
- 校验错误点击后能居中显示；校验页签显示问题数。
- 校验错误超过列表高度时在列表内部滚动，页面和画布尺寸不随错误数量变化。
- 编辑模式下可撤销/重做、复制粘贴、对齐。
- 重复连接两个已有路段相连的节点会提示且不新增路段。
- 双击路段能拆成两段；两条相邻路段能合并；单向路段能反转。
- 修改 X/Y 后关联路段长度变化。
- 切换路网时未保存修改会提示。
- 导出 PNG/SVG 内容与当前视图一致。
- 3D 预览能旋转缩放；重置视角能恢复初始机位；任务流向按起终点合并并显示数量。
- 修改画布尺寸后保存、刷新仍然生效。
