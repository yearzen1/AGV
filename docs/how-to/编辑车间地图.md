# 如何编辑车间地图

适用场景：你需要在「车间地图」里查看、对齐或修改路网，包括缩放预览、批量选择、整体拖动、新建节点和路段。

## 前置条件

- 已启动后端和前端，浏览器打开 <http://localhost:5173>。
- 已登录。`admin` 可以修改任何路网；`dispatcher` 只能查看预置模板（直接保存会提示「预置模板不可直接修改，请另存为副本」）。

## 步骤

### 1. 打开路网

左侧菜单「车间地图」→ 在左侧列表点选一张路网。页面会自动加载第一个路网。

列表里的「模板」标签表示预置数据。建议先点「另存为」得到副本，再在副本上修改。

### 2. 缩放和平移

| 操作 | 方式 |
|---|---|
| 放大/缩小 | 鼠标滚轮，以指针位置为中心，范围 40%–400% |
| 按钮缩放 | 工具栏 `−` / `+` |
| 重置为 100% | 点击工具栏中间的百分比 |
| 适应窗口 | 工具栏「适应窗口」，按所有节点的包围盒缩放并居中 |
| 平移 | 按住 `空格` + 左键拖动，或按住鼠标中键拖动 |

缩放和平移只改变查看视图，不会改变导出的节点坐标。

### 3. 选择元素（「选择/拖动」工具）

| 操作 | 结果 |
|---|---|
| 单击节点或路段 | 替换当前选择 |
| `Shift` / `Ctrl` / `Cmd` + 单击 | 把该元素加入或移出选择 |
| 在空白处按住左键拖出矩形 | 框选矩形内的节点，以及两端都在框内的路段 |
| `Shift` / `Ctrl` + 框选 | 追加到已有选择 |
| 工具栏「全选」或 `Ctrl/Cmd+A` | 选中所有节点和路段 |
| 工具栏「清空」或 `Esc` | 清空选择 |
| `Delete` / `Backspace` | 删除选中节点及其关联路段、选中路段 |

注意：框选和快捷键只在鼠标位于画布内时生效；光标在属性输入框里时不会触发。

### 4. 整体拖动

1. 选中要移动的节点或路段（可以框选或全选）。
2. 按住任意一个选中节点拖动，所有选中节点一起移动。
3. 如果选中的是路段，拖动时会带上该路段的两个端点。

拖动规则：

- 位移按 0.5 米吸附。
- 整组元素被限制在 0–50 米 × 0–34 米内，不会把节点拖出画布。
- 移动后，所有受影响路段的长度自动重算。

选中元素铺满整张画布时没有可移动余量，这是边界限制，不是拖动失效。

### 5. 新建节点和路段

新增节点的步骤：

1. 在工具栏选择「工位」「充电位」「缓存位」或「路口」。
2. 在画布空白处单击，节点落在吸附后的坐标上，并自动编号：
   - 工位 `W1`、`W2`…
   - 充电位 `CH1`…
   - 缓存位 `B1`…
   - 路口 `J1`…
3. 点「选择/拖动」回到选择模式，再拖动调整位置或在右侧属性面板改参数。

画布范围是 0–50 米 × 0–34 米，点击范围外不会新增节点。

新建路段：

1. 选「连路段」。
2. 依次点击两个节点，第一个节点会出现黄色描边。
3. 生成的路段默认双向、速度 1、容量 1，长度取两点欧氏距离。

重复路段和自环不会生成；再次点击同一个起点会取消连线。

### 6. 修改属性

- 只选中 1 个节点：右侧可改编号、类型、X、Y。
- 只选中 1 条路段：右侧可改编号、方向、长度、速度、容量。
- 多选时只显示已选数量，不提供批量属性表单。

### 7. 校验、保存、导入导出

- 「校验」：调用后端规则检查，问题会标红并显示在右侧。
- 「保存」：保存到当前路网；新建时需要先填名称。
- 「另存为」：复制为新路网。
- 「导入 JSON」：导入后自动校验。
- 「导出 JSON」：只导出 `nodes` 和 `edges`，不包含缩放、平移和选中状态。

## 验证

完成后应看到：

- 滚轮缩放时，指针下的节点基本停在原位。
- 点「100%」后视图回到初始大小；点「适应窗口」后所有节点都在画布内。
- 框选多个节点后拖动任意一个，其他被选节点按相同位移移动。
- 保存后刷新页面，节点坐标和路段长度与拖动结果一致。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 选中模板后保存失败 | 普通账号不能改预置模板 | 用「另存为」创建副本 |
| 全选后拖不动 | 地图已经铺满 0–50 × 0–34，没有位移余量 | 取消全选，只移动需要的元素 |
| 拖动时坐标只按 0.5 米跳 | 网格吸附的既定行为 | 需要更细坐标时在属性面板直接输入 |
| 按键没有反应 | 鼠标不在画布内，或焦点在输入框 | 先把鼠标移到画布上 |
| 缩放后担心导出坐标被改变 | 缩放只是视图变换 | 导出只包含节点坐标，不受缩放影响 |
