# 如何运行与观察仿真

适用场景：启动一次实时仿真，观察车辆运动、冲突等待和指标，并在演示时调整视角与画质。

## 前置条件

- 已启动后端（8080）和前端（5173），浏览器打开 <http://localhost:5173> 并登录。
- 目标路网至少有一个任务集；任务集的起终点必须是该路网的工位。
- 想观察双车道会车时，选择预置「双车道车间（会车演示）」并先为它创建一个任务集；分支巷道仍是单车道，只有主环路会出现左右两条车道。

## 1. 启动仿真

1. 进入「仿真运行」。
2. 选择路网，再选择该路网下的任务集。
3. 选择调度策略（`nearest` 就近分配 / `greedy-eta` 贪心 ETA）。
4. 设置 AGV 数量（1–12）和随机种子；同参数、同种子可复现同一结果。启动后这些参数会锁定，要改参数先「重置」。
5. 点「开始」。

启动后左侧是三维场景，右侧上方是实时指标，下方是「车辆 / 任务 / 节点 / 事件」四个页签；顶部标签显示「运行中 / 已暂停 / 已完成」。

## 2. 读懂右侧面板

### 2.1 实时指标

指标里的时间都以秒显示，括号内是原始 tick（1 tick = 100 ms）：

| 指标 | 含义 |
|---|---|
| 运行时长 | 从启动到当前帧经历的时间 |
| 完成 | 已完成任务数 / 总任务数，下方进度条同口径 |
| 完成时间 | 最后一件任务完成的时刻；全部完成前为 0 |
| 单均配送 | 每件任务从分配到达成的平均时长，含去取空驶、装货与送达 |
| 平均等待 | 总等待 tick ÷ AGV 数量，反映每台车平均被堵了多久 |
| 冲突 | 预约失败导致停车的次数，一次连续等待记 1 次 |
| 总里程 | 全部 AGV 实走弧长之和，含空驶 |
| 完成率 | 已完成任务占比 |

### 2.2 车辆

每行显示编号、状态、当前任务、任务起终点、在弧上的进度和已连续等待时长。把鼠标放在行上可以看到原始的弧编号与已行驶米数；点击行等同于在场景里选中该车。

| 状态 | 车身与灯光 | 含义 |
|---|---|---|
| 空闲 | 灰色 | 没有任务，停在充电位或节点 |
| 行驶 | 蓝色，前灯亮 | 正在前往目标 |
| 等待 | 红色呼吸灯 | 预约失败或下一段被占用 |
| 装卸 | 橙色，货箱抬起 | 在工位装货或卸货 |
| 充电 | 绿色，地面光环 | 回充中 |
| 完成 | 深灰 | 全部任务完成并回位 |

等待时事件日志会新增「冲突等待」记录，指标里的「冲突」「等待」随之增加。

### 2.3 任务

任务清单按任务编号排列，状态来自事件推送：

- **未分配**：还没分到车；
- **进行中**：某台车正在执行，显示车号；
- **已完成**：显示从分配到完成的实际用时。

任务清单只统计本次运行推送过的事件，刷新页面后从当前帧重新开始累计；进入页面之前就已完成的订单无法恢复用时，会在列表上方单独提示条数。

### 2.4 节点

节点表只列出**当前有车停靠**的节点，显示「预约 / 容量」。预约数超过容量才会标红。

一台车在工位等待时，会优先驶入相邻的缓存位，把工位空出来；缓存位被别的车占着时才会退而求其次，让出脚下节点的预约但人还停在原地。后者单独计为「N 台让位」，不进入预约数——它占的是物理空间，不是资源预约。

所以节点行可能是 `1 / 1`，也可能是 `1 / 1 · 另有 1 台让位`。出现「让位」说明缓存位当时不可用，属于容量不足时的兜底，不是数据算错。

场景里对应的节点会画一圈光环：琥珀色表示有车预约，红色表示预约满，白色圈是你刚点选的节点。点表格里的行可以在 3D 里定位该节点，再点一次取消。

### 2.5 事件

事件日志按发生顺序倒序显示，可用顶部下拉按类型过滤（任务分配、装货、完成、冲突等待、让位缓存、重规划、打破僵局、回充）。列表只保留最近 200 条，避免长时间运行时页面变慢；历史事件不落库，刷新后不保留。

## 3. 调整视角

| 操作 | 方式 |
|---|---|
| 旋转 | 左键拖动 |
| 平移 | 右键拖动 |
| 缩放 | 滚轮 |
| 聚焦某台车 | 双击车辆 |
| 跟随/取消跟随 | 单击车辆切换；再次单击同一车辆取消跟随；拖动视角自动退出跟随 |
| 俯视图 | 点工具栏「俯视」；再点一次恢复斜视 |
| 重置视角 | 按 `R`，按路网范围重新取景 |
| 快捷键 | `F` 跟随选中车辆，`T` 切换俯视，`R` 重置视角 |

单击车辆时，右侧「车辆状态」里对应行会高亮；单击空白处取消选中。

## 4. 标签与图层

工具栏「标签」控制节点编号和车辆编号：

- 打开：显示全部节点编号和车辆编号，适合讲解拓扑。
- 关闭：只保留车辆和地台，适合截图或投影演示。

方向箭头单独合并成一个网格：单向路段指向通行方向；双向双车道路段两条车道各指一个方向；单车道双向路段在前后两个位置放相反方向的箭头，表示两个方向共用一条通道。路面纹理只负责沥青和路缘，箭头长度固定，2 米短路段也不会被纹理裁切。路口处铺一块同材质的铺装，箭头和虚线在铺装边缘断开，不会从路口中间穿过去。

## 5. 切换画质

工具栏「画质」提供三档，选择会记在浏览器本地，下次进入沿用：

| 档位 | 阴影 | 环境反射 | 泛光 | 适用 |
|---|---|---|---|---|
| 低 | 无 | 无 | 无 | 集成显卡、投屏、远程桌面 |
| 中（默认） | 有 | 有 | 无 | 日常演示 |
| 高 | 有（更高分辨率） | 有 | 有 | 独显、录制视频 |

画质切换立即生效，不会重置仿真或视角。演示机器不确定时保持「中」，现场掉帧再切「低」。

## 6. 暂停、继续与调速

- 「暂停」冻结画面和仿真推进，「继续」从原 tick 恢复。
- 速度倍率 `0.5x / 1x / 2x / 4x` 只改变推送节奏，不改变仿真结果；调高倍速后车辆仍按时间插值平滑移动。没有在跑的仿真时倍速不可点。
- 运行期间路网、任务集、算法、AGV 数量和随机种子都锁定，避免前后端用不同参数推进同一场仿真。
- 「重置」清空当前仿真和画面，回到未开始状态，同时解锁参数并把倍速恢复成 `1x`。停止瞬间还在传输途中的旧帧会被丢弃，指标和车辆列表不会回跳。
- 刷新页面或切换菜单后重新进入，会通过 `/api/sim/status` 恢复当前用户的运行状态、参数和指标；事件日志只保留本次运行期间的推送。

## 7. 验证

- 启动后车辆从充电位出发，沿路段行驶，车头方向与箭头一致。
- 「车辆」页签每行都能读出状态、任务号与起终点；「任务」页签出现未分配 → 进行中 → 已完成的流转。
- 「节点」页签出现停在工位或充电位的车，占用数不超过容量；路口满员时标红。
- 出现冲突时车辆变红并呼吸，事件日志出现「冲突等待」，指标「冲突」与「平均等待」增加。
- 全部任务完成后「单均配送」不再为 0，数值等于任务页签里各任务用时的平均值（允许 1 tick 的四舍五入差）。
- 切换到俯视图，车辆位置仍贴合路面；双击车辆后相机持续跟随。
- 把画质切到「低」，阴影和光晕消失，帧率明显回升；切回「中」恢复。

## 8. 常见问题

**车辆看起来偏向路面一侧。** 双向双车道路段会把车辆画在右侧车道，这是视觉车道，不代表算法层有物理隔离；单向或单车道双向路段仍走中心线。

**画面卡顿。** 先切「低」画质；仍卡顿时关闭「标签」，并确认没有同时打开多个三维页面（车间地图的 3D 预览也占用一个 WebGL 上下文）。

**车辆一顿一顿。** 检查顶部「实时通道」是否已连接；意外断开时前端按 2/4/8/16/30 秒退避自动重试 5 次，仍失败就把标签标成「已断开」，点「重试」手动恢复。

**仿真结束后车都不见了。** 实时帧只在运行期间推送，结束后不保留逐帧位置；指标和历史实验仍可查看。
