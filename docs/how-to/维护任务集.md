# 如何维护任务集

适用于已经有一张可用路网、需要录入或修改一批搬运任务的情况。任务集必须绑定路网，任务的起点与终点只能是该路网的工位。

## 适用场景

- 新建一批搬运任务，供仿真运行或对比实验使用。
- 修改已有任务集的起终点或所属路网。
- 排查「任务起点不存在」「起终点不可达」等启动失败。

只想画地图请先看 [编辑车间地图.md](编辑车间地图.md)。

## 前置条件

- 已登录调度人员或管理员账号。
- 目标路网已保存且通过校验，至少包含两个工位（`WORKSTATION`）。

## 步骤

1. 打开「任务集」页面，点「新建任务集」。任务较多时先用列表上方的搜索框按名称或所属路网过滤，
   结果计数会随输入更新；清空搜索恢复完整列表。
2. 在弹窗顶部选择**所属路网**。任务集的节点候选只来自这张路网。
3. 填写名称，点「加一条」或「填充 20 单演示数据」生成任务行。
   - 「加一条」会优先选一组当前尚未使用的起终点，连续点击不会总是得到同一行；
   - 已有任务时，「填充 20 单演示数据」会先确认再覆盖；「清空」可一次性删除全部任务行，同样需要确认。
4. 为每行选择起点与终点：
   - 下拉里只出现该路网的工位，标签形如 `W1 · (2, 16)`；
   - 也可以点行内的「选点」，在弹出的小地图上直接点工位；
   - 起点与终点不能相同；
   - 删除任意一行后，剩余行的序号会自动重排为连续的 `1…N`。
5. 点「保存」。后端会校验每条任务的节点存在、类型为工位、起终点不同且可达。
   - 校验失败时，弹窗顶部会列出全部错误，并标红对应的任务行；修正后再次保存即可。

修改已有任务集时，弹窗会带出它绑定的路网。切换路网会清空当前任务行，因为节点编号只在单张路网内唯一。

## 验证

- 任务集列表的「所属路网」列显示正确的地图名称。
- 连续点「加一条」时，新行不会总是重复第一组起终点。
- 删除中间任意一行后，剩余行的序号仍然连续。
- 保存失败时，弹窗顶部能看到全部错误，并且对应任务行标红。
- 保存后重新打开任务集，起终点与所属路网保持不变。
- 「仿真运行」和「对比实验」的任务集下拉只列出与所选路网匹配的任务集。

## 常见问题

- **`任务集「xxx」绑定的路网与所选路网不一致`**：仿真或实验页面选错了路网。先选路网，再选该路网下的任务集。
- **`任务 3：起点 W9 不在该路网中`**：任务集来自其他路网，或路网改过编号。改绑路网或重新选择节点。
- **`任务 3：起点 CH1 不是工位`**：任务端点只能选工位。充电位、缓存位、路口不能作为取货或送货点。
- **`任务 3：W1 → W9 不可达`**：路网拓扑不连通。回到地图编辑器检查路段，或换一对工位。
- **`该路网被 N 个任务集使用，请先删除或改绑`**：删除路网前的保护。先删除引用它的任务集，或把任务集改绑到其他路网。

## 已知限制

修改路网不会自动迁移已有任务集。如果删除了某个工位或切断了通路，引用它的任务集会在下次保存或启动仿真时被校验拦下，按提示修改即可。
