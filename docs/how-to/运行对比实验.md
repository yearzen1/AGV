# 如何运行和阅读对比实验

适用场景：在「对比实验」页比较「就近分配」和「贪心 ETA」在同一路网、任务集、AGV 数量下的四项指标，并从历史实验里重新拉出两条记录做对比。

## 前置条件

- 已启动后端和前端，浏览器打开 <http://localhost:5173>。
- 已登录，且当前账号能看到「对比实验」菜单。
- 至少有一张路网和一个绑定该路网的任务集。

## 1. 运行一次对比

1. 选择「路网」和「任务集」。任务集下拉只显示绑定当前路网的任务集。
2. 设置「AGV 数量」。输入框右侧会显示当前路网允许的最大台数；超过上限会被钳制。
3. 设置「随机种子」。当前两种调度算法都是确定性实现，种子只用于记录和复现；相同参数换种子，结果不变。
4. 点「运行对比（两种算法）」。

运行完成后，页面会出现「指标对比」区：

- 参数快照：路网、任务集、AGV 数量、种子、运行时间；
- 结论条：哪套算法更优、差多少；
- 四张指标小图：完成时间、总路径长、总等待、冲突次数，各自独立坐标轴；
- 指标对比表：每行一个指标，两列算法值，外加差异和「更优」；差异按「第二列 − 第一列」计算，负数表示第二列更优；
- 状态说明：死锁/失败的实验没有完整指标，显示为 `-`，不参与图表；
- 「导出图表」：把四张指标小图合成一张 PNG；
- 「导出 CSV」：把指标对比表导出为 CSV，方便贴进汇报材料。

## 2. 指标口径

点「指标说明」可随时查看同样的说明：

| 指标 | 单位 | 口径 | 越小越好 |
|---|---|---|---|
| 完成时间 | tick | 最后一件任务完成的 tick；1 tick = 100ms | 是 |
| 总路径长 | 米 | 全部 AGV 实走弧长之和，含空驶 | 是 |
| 总等待 | tick | 处于 `WAITING` 的（车 × tick）之和 | 是 |
| 冲突次数 | 次 | 预约失败导致停车的事件次数，一次连续等待记 1 次 | 是 |

页面上会把 tick 换算成「几分几秒」作为辅助信息；论文和导出数据仍以 tick 为准。

## 3. 死锁和失败的读法

- 状态为「死锁」「失败」「已中断」的实验没有完整指标，历史表和对比表显示 `-`。
- 这类记录不能回放比对；「详情」里的「回放」按钮会禁用并提示原因。
- 想看死锁原因，点记录行的「事件」，在事件日志里看 `DEADLOCK` 或 `DEADLOCK_BREAK` 的 detail。

## 4. 从历史实验重新对比

1. 在「我的历史实验」里用状态、算法、路网、任务集、时间和关键字筛选。
2. 点一条记录的「对比」，再点另一条；历史表上方会出现「已选 1/2」「已选 2/2」。
3. 点「开始对比」。页面会滚回「指标对比」，用这两条记录重新画图和列表。
4. 如果两条实验的参数不同，会提示「参数不同，差异不能直接归因于算法」。

历史表只保留调度人员需要看的列：时间、场景（路网 + 任务集）、算法、AGV、状态、完成时间、总路径长、总等待、冲突、操作。实验 ID、种子、规则版本放在「详情」抽屉里。

## 5. 详情、事件与回放

- 「详情」：查看实验 ID、路网、任务集、AGV、种子、规则版本、状态、创建时间和四项指标；抽屉里也可以「加入对比」，加入后抽屉关闭，回到历史表上方继续选择第二条。
- 「事件」：打开该实验的任务级事件日志，可导出 CSV。
- 「回放」：只对 `FINISHED` 且有完整指标的实验开放；它是「用输入快照重跑一次并比对指标」，不是逐帧动画回放。

## 6. 结果保留

- 最近一次查看的对比结果会保存在浏览器本地；刷新页面后「指标对比」仍然在。
- 如果之后修改了顶部参数，结果区会提示「参数已变更，以下为上一次结果」。
- 点「清除」可移除本地保存的对比结果，不影响历史实验。

## 7. 验证清单

- 选择路网后，AGV 数量上限与当前路网充电位总容量一致。
- 运行对比后出现参数快照、结论条、四张独立指标图和对比表。
- 冲突次数在独立小图里可见，不再被完成时间的刻度压扁。
- 刷新页面后，上一次对比结果仍在；修改参数后出现「参数已变更」提示。
- 历史表路网/任务集显示名称；名称过长不撑高行，悬停可看全。
- 历史表筛选后分页、总数、清空筛选都正常。
- 选两条历史记录能重新生成对比；参数不同时有提示。
- 死锁/中断记录的「回放」不可用，并给出原因。
- 「指标说明」能解释 tick、米、车 × tick 和冲突次数的口径。
