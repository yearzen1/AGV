# 实验快照与回放

> 本文定义「实验输入快照」和「回放」的字段、接口与边界。
> 术语以 [领域模型与术语](领域模型与术语.md) 为准；为什么这样设计见 [领域模型说明](../explanation/领域模型说明.md)。

## 1. 用途

实验记录只保存 `roadnetId` / `taskSetId` 时，路网或任务集一旦被编辑，历史实验就无法证明「同参数还能得到同结果」。

因此每次创建实验时，把**当时的整张路网 JSON 和任务集 JSON** 一起存进实验记录。
回放时直接用快照重建输入，不读取当前库里的路网和任务集。

## 2. 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `experiment.roadnet_snapshot` | `LONGTEXT`，可空 | 创建实验时的 `RoadNetPayload` 原文 |
| `experiment.taskset_snapshot` | `LONGTEXT`，可空 | 创建实验时的 `TaskSetPayload` 原文 |
| `experiment.algorithm` | 字符串 | 回放使用的调度算法码 |
| `experiment.agv_count` | 整数 | 回放使用的 AGV 数量 |
| `experiment.seed` | 整数 | 回放使用的随机种子 |

快照写入后不可修改。`roadnetId` / `taskSetId` 仍然保留，用于按路网和任务集筛选，不参与回放重建。

## 3. 写入时机

| 入口 | 状态 | 快照来源 |
|---|---|---|
| `POST /api/experiment/run`、`/compare` | `FINISHED` / `FAILED` | 运行前读取的路网、任务集原文 |
| `POST /api/sim/start` | `RUNNING` | 启动前读取的路网、任务集原文 |

读取失败或路网/任务集在运行前被删除时，实验不会创建，接口返回 `400`。
实验记录一旦创建，快照就固定；之后修改路网不会影响这条记录。

## 4. 回放接口

```http
POST /api/experiment/{id}/replay
Authorization: Bearer <token>
```

请求体为空。回放会：

1. 读取该实验的 `roadnet_snapshot` / `taskset_snapshot`；
2. 用记录中的 `algorithm`、`agv_count`、`seed` 重新运行一次离线实验；
3. 新建一条实验记录（同样保存快照），并写入新的指标；
4. 把新旧四项指标逐项比较，返回 `consistent`。

响应示例：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "experimentId": 12,
    "replayId": 18,
    "consistent": true,
    "original": {
      "id": 12,
      "algorithm": "nearest",
      "algorithmName": "就近分配",
      "agvCount": 3,
      "seed": 20261107,
      "status": "FINISHED",
      "makespan": 948,
      "totalPathLen": 412.7,
      "totalWaitTick": 63,
      "conflictCount": 4,
      "createTime": "2026-11-10T10:12:30"
    },
    "replay": {
      "id": 18,
      "algorithm": "nearest",
      "algorithmName": "就近分配",
      "agvCount": 3,
      "seed": 20261107,
      "status": "FINISHED",
      "makespan": 948,
      "totalPathLen": 412.7,
      "totalWaitTick": 63,
      "conflictCount": 4,
      "createTime": "2026-11-10T15:40:02"
    }
  }
}
```

### `consistent` 判定

四项指标全部相等且两次状态都是 `FINISHED` 时为 `true`：

- `makespan`
- `totalPathLen`（保留一位小数后比较）
- `totalWaitTick`
- `conflictCount`

只要任一项不同或任一次状态不是 `FINISHED`，返回 `false`，但回放记录仍然保存，便于排查。

## 5. 错误与边界

| code | HTTP | 场景 |
|---|---|---|
| 4005 | 400 | 实验没有输入快照（功能上线前的历史记录） |
| 4006 | 400 | 实验没有指标记录（`FAILED` / `ABORTED`），无法比对 |
| 4030 | 403 | 不是实验创建人，也不是管理员 |
| 4040 | 404 | 实验不存在 |

快照解析失败说明库里的 JSON 被人工改坏了，返回 `4002`（数据损坏），不会回退到当前路网重跑。

## 6. 与逐帧回放的区别

- 本文的回放是**输入回放**：重跑一次仿真，复算指标。
- 不保存、也不重放每个 tick 的帧和事件；那需要独立的事件日志，当前明确不做。
- 因此回放能回答「结果是否可复现」，不能回答「第 317 tick 时哪台车在哪里」。

## 7. 兼容性与迁移

- 新列由 Flyway `V2__experiment_snapshot.sql` 增加，可空。
- 旧实验的 `roadnet_snapshot` 为空，列表照常展示，回放返回 `4005`。
- 不需要回填旧数据；如果确实要回放旧实验，只能重新运行一次生成新记录。
