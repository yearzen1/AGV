# 界面与交互规范

本仓库前端的视觉、布局、组件与可访问性约定。改页面前先对齐本规范。

## 1. 视觉方向

明亮现代 SaaS：浅灰底、白色卡片、细边框、大圆角、克制的阴影，主色为靛蓝。
深色只保留给三维场景、登录页品牌插画和少量强调块；侧边栏、表格、弹窗一律浅色。

- 关键词：干净、留白、层次、低噪声。
- 禁止：大面积渐变面板、重投影、彩色描边卡片、默认 Element Plus 蓝。
- 页面标题不重复：页头只出现一次 `h1`，内容区不再放同名标题。

## 2. 设计令牌

令牌定义在 `agv-frontend/src/styles/global.css` 的 `@theme` 与 `:root` 中，页面只引用变量或 Tailwind 语义类。

| 令牌 | 值 | 用途 |
|---|---|---|
| `background` | `#f7f8fa` | 页面底色 |
| `foreground` | `#0f172a` | 主文字 |
| `card` | `#ffffff` | 卡片、面板 |
| `muted` | `#f1f3f7` | 次级底色、表头 |
| `muted-foreground` | `#64748b` | 说明文字 |
| `border` | `#e6e8ee` | 分隔线、输入框描边 |
| `primary` | `#4f46e5` | 主按钮、选中态、链接 |
| `primary-soft` | `#eef2ff` | 选中背景、图标底 |
| `success` | `#059669` | 已完成、连接正常 |
| `warning` | `#d97706` | 运行中、待处理 |
| `danger` | `#dc2626` | 失败、冲突 |
| `radius` | `12px` | 输入框、按钮 |
| `radius-lg` | `16px` | 卡片、弹窗 |

字体栈：`Inter, "SF Pro Text", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
数字与 tick 使用 `font-variant-numeric: tabular-nums`。

## 3. 实现栈

- 布局与自定义组件使用 Tailwind CSS v4 工具类和 `src/components/ui/` 下的本地组件。
- 不启用 Tailwind Preflight，避免重置 Element Plus 的表格、下拉与弹窗结构。
- 数据密集控件（表格、下拉、数字输入、分页、对话框）继续使用 Element Plus；
  其外观通过 `global.css` 的组件级变量覆盖成同一套视觉语言。
- 图标使用项目内 `AppIcon` 或内联 SVG，不引入第二套图标库。
- 新组件只写在 `src/components/ui/`，不在业务页面里复制粘贴第二份按钮/卡片样式。

## 4. 布局与断点

| 宽度 | 导航 | 主内容 |
|---|---|---|
| `> 1024px` | 白色侧栏，232px，右侧 1px 分隔线 | 页头 64px + 内容区，`24–28px` 内边距 |
| `768–1024px` | 侧栏收窄为图标栏 | 内容区单列 |
| `< 768px` | 收进抽屉，由页头菜单按钮唤出 | 单列，内边距 16px |

- 卡片网格用 `repeat(auto-fit, minmax(...))` 或 Tailwind `grid-cols-*` 响应式类。
- 仿真页在 `1366×768` 不能出现页面纵向滚动；三维场景随高度伸缩。
- 任务集弹窗宽度 `min(880px, 94vw)`，小屏不超出视口。

## 5. 页面模式

### 登录

- 左侧品牌区使用柔和靛蓝渐变与网格纹理，右侧白色表单卡片。
- 不展示课程、毕设、选题等非产品信息。
- 原生 `<form>` 提交，回车与按钮同一路径。

### 概览

- 顶部一张主色渐变 Hero，包含一句话说明与「启动仿真 / 维护任务集」入口。
- 四张统计卡：路网、任务集、实时通道、仿真服务。
- 中部快捷入口，底部「最近实验 + 路网清单」双栏。
- 连接自检折叠到页面底部，默认关闭。

### 数据页（任务集 / 对比实验 / 管理）

- 页面说明一行，随后是白色卡片。
- 列表头：标题 + 数量 + 搜索/筛选 + 主操作，全部在同一行内可换行。
- 表格使用斑马纹之外的低对比悬停；状态一律用 pill 标签。
- 未运行或空结果必须有占位说明和下一步入口。

### 仿真运行

- 顶部工具条保留参数、播放、视图三段；参数顺序固定。
- 三维场景为深色主视觉，右侧为白色指标/车辆/事件卡片。
- 场景左下角常驻 `F / T / R` 快捷键提示。
- 指标 6 项，保持原顺序；结束态用状态标签和进度条表达。

### 车间地图

- 左侧路网列表与任务流向，右侧编辑器，画布为白色纸面。
- 工具栏保持两行、不换行；浮层不遮挡节点标签。

## 6. 可访问性

- 每个页面只有一个 `h1`（页头标题），卡片标题用 `h2`。
- 页头提供「跳到主要内容」，目标 `#main-content`，`tabindex="-1"`。
- 所有交互控件保留 `:focus-visible` 描边。
- 当前菜单项使用 `aria-current="page"`，不能只靠颜色。
- 状态变化放入 `role="status"` / `aria-live="polite"`；登录错误用 `role="alert"`。
- 尊重 `prefers-reduced-motion: reduce`，关闭循环与过渡动画。
- 图标按钮必须有 `aria-label`；装饰图标 `aria-hidden="true"`。

## 7. 表单

- 登录页使用原生表单：`autocomplete="username"` / `"current-password"`，允许粘贴。
- 提交时校验，错误写到 `role="alert"` 区域，并把焦点移到第一个错误字段。
- 用户重新输入后立即清除错误，不在输入过程中持续报错。
- 密码显示切换是 `type="button"`，带 `aria-pressed`。
- Caps Lock 开启时在密码下方给出非阻断提示。

## 8. 页面状态

| 状态 | 约定 |
|---|---|
| 加载中 | 表格 `v-loading`，统计卡用骨架或 `—`，不显示假 0 |
| 空 | 说明为什么为空 + 下一步入口，不只写「暂无数据」 |
| 错误 | 页面内可见文案；toast 只做补充，不承担唯一反馈 |

## 9. 验收清单

自动：

```bash
cd agv-frontend
npm run type-check
npm run build
npm test
npm run e2e:roadnet
npm run e2e:taskset
npm run e2e:sim
npm run e2e:scene
```

人工：

- [ ] 登录页没有毕设/选题信息；窄屏单列可滚动。
- [ ] 侧栏为浅色，当前项有 `aria-current` 与背景双重标识。
- [ ] 概览首屏能看到 Hero、统计卡和快捷入口。
- [ ] 任务集搜索、空状态、弹窗在 94vw 内正常。
- [ ] 对比实验未运行时显示占位；运行后图表与结论徽标正常。
- [ ] 仿真页 `1366×768` 无纵向页面滚动；快捷键提示不遮挡车辆。
- [ ] 所有页面无横向溢出，浏览器标题随路由变化。

## 10. 非目标

- 不重做三维场景的坐标、插值、画质与阴影。
- 不提供深色主题切换。
- 不改变接口、错误码与领域术语。
- 不为了视觉替换重写建图编辑器的交互逻辑。
