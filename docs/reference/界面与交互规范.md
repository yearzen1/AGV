# 界面与交互规范

本仓库前端的统一视觉、布局、可访问性与状态约定。改页面、改样式或新增交互前先对齐本规范，
避免各页面各写一套。

## 适用范围

- 前端 Shell（侧边导航、页头、主内容区）
- 登录页、概览页、任务集页、仿真运行页、对比实验页
- 表单校验、加载态、空状态、错误提示

不包含：三维场景内部的坐标与渲染规则（见 [三维场景渲染](../explanation/三维场景渲染.md)）、
后端接口字段与错误码（见 [README](../../README.md)）。

## 1. 设计令牌

品牌色与中性色统一在 `agv-frontend/src/styles/global.css` 的 `:root` 中定义，页面只引用变量，
不直接写新的十六进制色值。

| 令牌 | 用途 |
|---|---|
| `--agv-brand` | 主色，按钮、选中态、关键数字 |
| `--agv-brand-strong` | 侧边栏与深色背景 |
| `--agv-surface` | 卡片、面板底色 |
| `--agv-surface-muted` | 页面底色 |
| `--agv-border` | 分隔线、输入框描边 |
| `--agv-text` / `--agv-text-muted` | 正文 / 次要文字 |
| `--agv-radius` / `--agv-radius-lg` | 控件 / 面板圆角 |
| `--agv-shadow` | 面板默认阴影 |

Element Plus 的 `--el-color-primary*` 继续映射到品牌色，保证组件库与自定义样式一致。

## 2. 布局与断点

| 宽度 | 侧边导航 | 主内容 |
|---|---|---|
| `> 900px` | 常驻 220px 深色侧栏 | 页头 + 可滚动主区域 |
| `≤ 900px` | 收进抽屉，由页头「打开菜单」按钮唤出 | 单列，页面内边距收紧到 12px |

- 侧栏菜单项必须同时有图标与文字，当前路由用 `aria-current="page"` 和背景色双重标识，不只靠颜色。
- 仿真运行页在 `1366×768` 及以上不得出现纵向页面滚动条；场景随窗口高度缩放。
- 卡片网格使用 `repeat(auto-fit, minmax(...))` 或 `flex-wrap`，不写死在某个像素宽度。
- 任务集编辑弹窗宽度使用 `min(860px, 94vw)`，小屏不超出视口。

## 3. 可访问性

- 每个页面只有一个 `h1`（页头标题），面板标题用 `h2`。
- 页头前提供「跳到主要内容」跳转链接，键盘聚焦时才可见；目标为 `#main-content`。
- 所有可交互控件保留 `:focus-visible` 描边，禁止用 `outline: none` 直接抹掉。
- 图标按钮必须有可访问名称（`aria-label`），纯装饰图标加 `aria-hidden="true"`。
- 状态变化（仿真状态、通道状态、登录错误）放在 `role="status"` 或 `role="alert"` 区域，
  用 `aria-live` 播报；不要只在右下角弹一次性提示。
- 尊重 `prefers-reduced-motion: reduce`：关闭过渡与循环动画，保留最终视觉状态。

## 4. 导航与标题

- 路由 `meta.title` 同时用于页头标题和浏览器标签页标题，格式为 `页面名 · 排策智演`。
- 登录页标题固定为 `登录 · 排策智演`。
- 菜单当前项由 `aria-current="page"` 标识；浏览器前进/后退后仍要同步。
- 窄屏点击菜单项后自动关闭抽屉。

## 5. 表单

登录页是唯一不依赖 Element Plus 表单校验器的入口表单，约定如下：

- 使用原生 `<form>` 包裹，提交按钮 `type="submit"`，回车与点击走同一条路径。
- 用户名 `autocomplete="username"`，密码 `autocomplete="current-password"`；禁止禁用粘贴。
- 校验时机：提交时校验，错误写入 `role="alert"` 区域并把焦点移到第一个错误字段；
  用户重新输入后立即清除错误，不在输入过程中持续报错。
- 密码框提供可访问的显示/隐藏切换，按钮带 `aria-pressed`。
- Caps Lock 开启时在密码下方给出非阻断提示。
- 演示账号按钮只负责填充表单，不自动提交。

## 6. 页面状态

每个数据页面必须覆盖三种状态：

| 状态 | 约定 |
|---|---|
| 加载中 | 表格用 `v-loading`，卡片/统计用骨架屏；不要显示「0」或空表冒充结果 |
| 空 | 用一句话说明为什么为空、下一步点哪里；不要只显示「暂无数据」 |
| 错误 | 页面内可见的错误文案，保留重试入口；错误不吞掉、不只弹 toast |

- 概览页的「连接自检」属于开发者工具，默认折叠，不占用首屏。
- 任务集列表提供按名称/所属路网过滤的搜索框，结果计数随过滤更新。
- 对比实验未运行时显示结果占位说明，不渲染空白图表容器。

## 7. 仿真运行页

- 工具栏参数顺序固定：路网、任务集、算法、AGV 数量、随机种子；
  `e2e-simulation` 依赖 `.toolbar .field-label` 的文本与顺序。
- 播放控制与视图控制排在参数之后，用视觉分隔线区分，不改变参数控件类名。
- 3D 场景左下角显示快捷键提示：`F` 跟随、`T` 俯视、`R` 重置视角；提示为半透明浮层，
  不遮挡车辆与节点。
- 指标保持 6 项、顺序不变，进度条使用 `el-progress` 并显示百分比。
- 「车辆状态」「事件日志」使用 `h2` 标题；空列表给出原因与下一步。仿真结束时提示
  位置只在运行期间可见。

## 8. 验收清单

自动：

```bash
cd agv-frontend
npm run type-check
npm run build
npm test
npm run e2e:roadnet     # 需后端 8080 与前端 5173
npm run e2e:taskset
npm run e2e:sim
```

人工：

- [ ] Tab 从页面顶部开始，第一站是「跳到主要内容」；回车后焦点落到主区域。
- [ ] 侧栏当前项读屏播报「当前页」，切换路由后标签页标题同步变化。
- [ ] 登录时留空用户名或密码，错误区域被读屏播报且焦点回到缺失字段；
      重新输入后错误立即消失。
- [ ] 窄屏（≤ 900px）打开抽屉菜单，点击任一项后抽屉关闭并完成跳转。
- [ ] 概览页首屏能看到统计、快捷入口和路网清单；连接自检默认折叠。
- [ ] 任务集搜索输入不存在的名称时显示空状态，清空后恢复全部列表。
- [ ] 仿真页 `1366×768` 无纵向页面滚动，快捷键提示不遮挡车辆。
- [ ] 系统开启「减少动态效果」后，页面切换和提示动画不再循环。

## 9. 非目标

- 不引入 UI 组件库、图标库或 CSS 框架；图标使用内联 SVG。
- 不重做三维场景渲染，不改变场景坐标与画质档位含义。
- 不增加深色主题切换；深色只用于侧边栏和登录页品牌区。
