# 审计日志

> 本文定义业务审计日志的记录范围、字段和查询接口。
> 它和 SLF4J 运行日志是两件事：运行日志给开发者排障，审计日志给管理员追溯「谁在什么时候改了什么」。

## 1. 用途

答辩和实际演示里经常需要回答：

- 这张路网是谁改的？什么时候改的？
- 这条任务集的删除操作是谁做的？
- 谁启动了仿真、跑了哪组实验？
- 有人连续登录失败吗？

审计日志只记录**有业务含义的动作**，不记录每次请求、也不记录仿真 tick。

## 2. 表结构

表名 `sys_audit_log`，由 Flyway `V3__audit_log.sql` 创建。

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | `BIGINT` 主键 | 应用侧雪花算法生成，数据库不自增；见 [数据库设计](数据库设计.md) |
| `username` | `VARCHAR(64)`，可空 | 操作人；登录失败时填尝试的用户名，匿名操作填 `null` |
| `action` | `VARCHAR(48)` 非空 | 动作码，见第 3 节 |
| `target_type` | `VARCHAR(32)`，可空 | 对象类型：`USER`、`ROADNET`、`TASKSET`、`SIM`、`EXPERIMENT` |
| `target_id` | `VARCHAR(64)`，可空 | 对象 ID 或用户名 |
| `result` | `VARCHAR(16)` 非空 | `SUCCESS` / `FAILURE` |
| `detail` | `VARCHAR(500)`，可空 | 失败原因或补充说明 |
| `ip` | `VARCHAR(64)`，可空 | 请求来源 IP；后台线程触发时为 `null` |
| `create_time` | `DATETIME` 非空 | 记录时间 |

## 3. 动作清单

| action | target_type | 触发点 |
|---|---|---|
| `LOGIN` | `USER` | 登录成功或失败 |
| `ROADNET_CREATE` | `ROADNET` | 新建路网、套模板导入 |
| `ROADNET_UPDATE` | `ROADNET` | 保存路网 |
| `ROADNET_DELETE` | `ROADNET` | 删除路网 |
| `TASKSET_CREATE` | `TASKSET` | 新建任务集 |
| `TASKSET_UPDATE` | `TASKSET` | 保存任务集 |
| `TASKSET_DELETE` | `TASKSET` | 删除任务集 |
| `USER_CREATE` | `USER` | 管理员新建账号 |
| `USER_UPDATE` | `USER` | 管理员修改账号 |
| `USER_DELETE` | `USER` | 管理员删除账号 |
| `SIM_START` | `SIM` | 启动实时仿真 |
| `SIM_RESET` | `SIM` | 重置仿真 |
| `EXPERIMENT_RUN` | `EXPERIMENT` | 离线实验每生成一条实验记录 |
| `EXPERIMENT_REPLAY` | `EXPERIMENT` | 回放实验 |

新增动作时必须先更新本表，再写代码。

## 4. 记录规则

- **只记成功操作 + 登录失败**。业务校验失败（如路网不合法）由接口错误码表达，不写审计。
- **审计写入失败不影响业务**：记录异常只打 `WARN` 日志，不向上抛。
- **使用独立事务**：审计行在业务事务之外提交，避免业务回滚时把日志一起回滚。
- 审计日志不自动清理。数据量大时由管理员按时间手工归档，当前不提供删除接口。

## 5. 查询接口

```http
GET /api/admin/audit?page=0&size=20&action=LOGIN&username=admin
Authorization: Bearer <admin-token>
```

| 参数 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `page` | 否 | `0` | 从 0 开始 |
| `size` | 否 | `20` | 1–100 |
| `action` | 否 | 空 | 按动作码模糊匹配 |
| `username` | 否 | 空 | 按操作人模糊匹配 |

响应按 `id` 倒序：

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "total": 128,
    "page": 0,
    "size": 20,
    "records": [
      {
        "id": 128,
        "username": "admin",
        "action": "ROADNET_UPDATE",
        "targetType": "ROADNET",
        "targetId": "1",
        "result": "SUCCESS",
        "detail": null,
        "ip": "127.0.0.1",
        "createTime": "2026-11-10T15:42:07"
      }
    ]
  }
}
```

## 6. 错误与边界

| code | HTTP | 场景 |
|---|---|---|
| 4000 | 400 | `page < 0` 或 `size` 不在 1–100 |
| 4030 | 403 | 非管理员访问 |

## 7. 和运行日志的分工

| | 审计日志 | 运行日志 |
|---|---|---|
| 存储 | 数据库 `sys_audit_log` | 控制台 / 日志文件 |
| 读者 | 管理员、答辩演示 | 开发者 |
| 内容 | 谁做了什么、结果如何 | 异常堆栈、调度细节、性能 |
| 保留 | 长期 | 按日志轮转 |
